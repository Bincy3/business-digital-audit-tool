# AuditTool

AuditTool is a small Python utility to perform a quick digital presence audit of a business website. It checks common SEO, contact, social, technical, and conversion readiness items and produces both a plain-text and a clean HTML report.

## Features
- Validates website URL and handles unreachable or blocked sites
- Checks: title, meta description, H1, images missing alt, social links, phone, email
- Technical checks: HTTPS, sitemap.xml, robots.txt, mobile viewport
- Open Graph tag detection for social sharing
- Category-based scoring: SEO, Contact, Social, Technical, Conversion
- Produces `sample_report.txt` and `sample_report.html`

## Setup
1. Create a Python 3.8+ virtual environment (recommended):

```bash
python -m venv .venv
source .venv/bin/activate   # macOS / Linux
.venv\Scripts\Activate     # Windows PowerShell
```

2. Install dependencies:

```bash
pip install -r requirements.txt
```

## Usage
Run the CLI and follow prompts:

```bash
python app.py
```

Enter the business name, industry, and website URL (with or without scheme). The tool will save `sample_report.txt` and `sample_report.html` in the project folder.

## Output sample
- `sample_report.html` — a visual HTML report you can open in a browser.
- `sample_report.txt` — a plain text summary.

## Notes
- The tool uses simple heuristics and public page scraping; it does not log into the site.
- If you plan to audit many sites, be mindful of rate limits and the target site's robots guidelines.
